# Future prototype discussion

**Planning only. The founder explicitly instructed on 2026-09-19 not to start the project now. No implementation, prototype construction, deployment, or autonomous development is currently authorized.**

The following records ideas for a later assignment; it is not an active task.

## Possible first result

A shareable website with one fictional person's information, stories, and photographs. Use existing text/file authoring. Astro is the favored candidate. Consider a photo-led memoir and a focused album-layout comparison, rather than building multiple complete products.

## What could be worth testing later

- Whether a few imperfect notes/photos produce a coherent, attractive reading experience without mandatory life stages or dates.
- Whether a selected collection excludes all other stories and media from its generated output.
- Whether ordinary source documents can be imported without losing originals or overwriting local edits.
- Whether one photo-heavy chapter prints well, including captions, page breaks, and sensible audio references.

## Possible book feature

Select entries and order, optionally group them into chapters, add a title/cover, and render a print edition. Selection could live in a simple file; no new document editor is needed. Screen and print layouts can differ while using the same content. The founder accepted website-first sequencing with early exploration of how book output works.

## Sharing recommendation to investigate later

Readers receive a normal URL. A selected public collection omits unselected material entirely. A protected family collection could use host/server-enforced access covering pages and media. The founder delegated the technical choice; no host or authentication method has been selected.

## Planning method

Keep plain Markdown notes now. OpenSpec can be reconsidered for a concrete future change if useful. It has not been installed and is not required.
