# Simulated creator perspectives

Recorded 2026-09-19 at the founder's request in Q14. Three agents imagined creators using the project. They shared the project context; these are speculative design inputs, not real user interviews or validation.

| Perspective | Main needs | Preferred presentation |
| --- | --- | --- |
| Adult child preparing a parent's collection | Start with one story; preserve exact words where wanted; accept unfinished/undated material; choose funeral and family selections; keep usable originals | Quiet, photo-led memoir with optional chapters |
| Aunt preparing a coming-of-age gift | Mix short memories, long stories, quotations, and photos; preview quickly; express personality; exclude intimate material; hand the files to the recipient | Warm photographic keepsake with optional chronology |
| Family editor using documents and recordings | Use existing files; distinguish original words from edited prose; correct details easily; preview what each audience receives; read on phones; print selected material | Readable memoir with related stories and relevant audio |

All suggested omitting a custom document editor, mandatory biography questionnaires, and extensive social features initially. Similarity may reflect their shared context rather than general preferences.

Working recommendation for future consideration: a photo-led memoir, one smaller album-layout comparison using identical content, and one printable chapter to investigate captions/page breaks. These are hypotheses, not selected designs or authorization to build.
